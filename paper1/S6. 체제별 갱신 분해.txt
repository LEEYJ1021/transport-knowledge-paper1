# # 지금까지의 연구를 쉽게 풀어 쓴 정리
# ## 1. 어떤 연구인가
# **한 줄 요약:** 교통 분야 학술 논문 약 11만 편을 모아서, "교통 연구의 주제가 시간에 따라 어떻게 바뀌었고, 그 변화가 누구에 의해, 어디서 일어났는가"를 데이터로 알아보는 연구입니다.
# 비유하면 이렇습니다. 도서관에 25년치 교통 논문이 쌓여 있습니다. 이 논문들을 주제별로 150묶음으로 나누고, 해마다 어떤 묶음이 커지고 작아졌는지 봅니다. 그리고 그 변화가 진짜 연구 흐름의 변화인지, 아니면 "어떤 학술지가 더 많은 논문을 싣게 되었다" 같은 착시인지 가려냅니다.

# **연구 질문 5개 (계획서 기준)**

# | 번호 | 질문 | 쉬운 말 |
# |---|---|---|
# | RQ1 | 주제 구조는 언제 "체제"가 바뀌었나 | 어느 해를 기점으로 연구 지형이 달라졌나 |
# | RQ2 | 그 변화는 구성 변화인가, 내재 변화인가 | 학술지 비중이 바뀐 탓인가, 같은 학술지 안에서 바뀐 것인가 |
# | RQ3 | 갱신은 적응, 재배분, 진입, 퇴출 중 무엇인가 | 기존 연구자가 주제를 바꿨나, 새 연구자가 들어왔나 |
# | RQ4 | 지식 생산은 어디서, 누구에 의해 이뤄지나 | 미국·중국 등 나라별 몫이 어떻게 변했나 |
# | RQ5 | 주제별 공급은 지역별 부담과 맞나 | 연구가 실제 필요가 큰 곳을 향하나 |

# ## 2. 연구는 어떻게 진행되었나 (단계별)
# 이 연구의 특징은 **"결과를 보기 전에 규칙을 먼저 정해서 도장 찍어 두는 것(사전등록·동결)"**을 철저히 한다는 점입니다. 시험 문제를 풀기 전에 채점 기준을 봉투에 넣고 봉인하는 것과 같습니다. 결과를 본 뒤 기준을 슬쩍 바꾸는 것을 막기 위해서입니다.
# | 단계 | 한 일 | 비유 |
# |---|---|---|
# | **S0** 사전등록 | 오염된 논문 269편(표지, 목차 등)을 제외하고 규칙을 동결 | 재료 손질 + 규칙 봉인 |
# | **S1** 국가 층 | 논문 8만여 편에 저자 소속 국가를 붙임. 사람이 200건 검수해 200/200 정확 | 논문마다 "어느 나라 연구자인가" 라벨 |
# | **S2** 측정 교정 | 가중치, 결측, 위험군(동명이인 가능 이름) 점검, 외부 DB(Scopus) 대조 | 측정 도구의 눈금 검사 |
# | **S3** 증거 카드 | 150개 주제 각각을 대표 단어, 대표 논문, 안정성으로 점검해 A/B/C 등급 | 주제마다 신분증 발급 |

# ## S6-1. 분석 단위와 변수 구축
# **저자×기간 표를 만듭니다.** 행은 저자, 기간, 저널, 토픽이고 값은 가중 논문 질량입니다.
# - **분석 논문:** 주제 논문(토픽 보유)만 씁니다. 결측 21%는 S4의 역확률 가중(1·99 백분위 절단)을 재사용하되 F2 파생 변수는 공변량에 넣지 않습니다(S4와 같은 순환 방지 규칙).
# - **저자 질량 `w_a`:** 기간 내 저자의 가중 논문 질량을 전체 합이 1이 되게 정규화합니다. 가중치 4종(equal, inv_n_authors, first_last, full_count)마다 따로 만듭니다. 알파벳순 저자 논문은 first_last에서 제외하고 equal로 처리합니다(S2.1 규칙).
# - **저자 토픽 분포 `s_ak`:** 저자의 기간 내 토픽 비중입니다(합 1).
# - **역할 정의(제안):** 인접 기간 쌍 (t0, t1) 기준입니다.
# | 역할 | 정의 |
# |---|---|
# | 지속 | 두 기간 모두 주제 논문이 있는 저자 |
# | 진입 | t1에만 있고 코퍼스 첫 출판 연도가 t1 안인 저자 |
# | 퇴출 | t0에만 있고 이후 어떤 연도에도 논문이 없는 저자 |
# | 복귀 | t1에만 있으나 첫 출판이 t0 이전인 저자(별도 칸) |
# - **복귀 칸이 필요한 이유:** 기간만 보면 이전에 활동했던 저자가 "진입"으로 잡혀 진입 몫이 부풀려집니다. F4의 `first_year`가 주제 없는 논문까지 포함한다고 S2.3에 적혀 있으니 진입 판별에 쓸 수 있습니다. 퇴출 판별에 쓸 마지막 출판 연도 열이 있는지는 확인하지 못했습니다. 없으면 F1·F2에서 만들어야 합니다.
# - **퇴출은 마지막 쌍(2015–19→2020–25)에서 정의되지 않습니다.** 이후 자료가 없는 우측 절단입니다. 그 쌍은 퇴출 항을 "정의 불가"로 두고, 적응·재배분·진입만 보고하며 나머지는 그 합에 포함시키지 않습니다. 첫 기간(≤2004)도 1990년대 자료가 있어도 임베딩 보유율이 낮아 진입 판별이 불안정하므로, 첫 쌍(≤2004→2005–09)은 주 분석에 포함하되 같은 한계를 적습니다.
# - **저자당 논문 1편 문제:** 지속 저자의 42%가 기준 기간에 주제 논문 1편이라 `s_ak`가 0/1에 몰립니다. 이 때문에 적응 항이 잡음으로 부풀 수 있습니다. 대응은 다음 세 가지를 병행하는 것입니다(S2.5 규칙).
#   - 논문 3편 이상 부분표본
#   - split-half 신뢰도
#   - 질량 가중 집계(저자 수 가중이 아니라 논문 질량 가중)

# ## S6-2. 4항 분해 (6.1)
# 기간 쌍마다 각 토픽 k의 총변화 `ΔS_k = S_k(t1) − S_k(t0)`를 분해합니다. `S̄_k`는 두 기간 집계 비중의 평균, `w̄`, `s̄`는 중점 평균입니다.
# `ΔS_k = Σ_지속 w̄_a·Δs_ak (적응) + Σ_지속 (s̄_ak − S̄_k)·Δw_a (재배분) + Σ_진입 w_a1·(s_a1k − S̄_k) (진입) − Σ_퇴출 w_a0·(s_a0k − S̄_k) (퇴출)`
# (복귀 저자는 진입 항에 넣고 별도 칸으로 따로 출력합니다.)
# - **중심화(`− S̄_k`)가 필요한 이유:** 지속 저자의 질량이 줄면 그 몫이 진입으로 흘러가는데, 중심화가 이 이동을 정확히 닫아 줍니다. 제가 항을 정리해 검증했지만 코드에서 반드시 불변식으로 확인하세요.
# - **불변식:** 네 항의 합이 모든 토픽에서 `ΔS_k`와 1e-9 이내로 같아야 합니다. 질량 보존(각 기간 `Σ_a w_a = 1`, 토픽 합 `Σ_k S_k = 1`)도 확인합니다. 실패하면 그 실행의 수치는 폐기합니다(S4 규칙).
# - **요약 지표:** 토픽별 값이 아니라 쌍마다 다음을 보고합니다.
#   - 총변화의 크기 `½Σ_k|ΔS_k|`
#   - 네 항 각각의 절대 기여 `½Σ_k|항_k|`와, 이를 네 항의 절대 기여 합으로 나눈 몫. 네 항이 서로 상쇄할 수 있으므로 몫은 "합이 1"이 되도록 정의를 분명히 적습니다.
#   - 신생 정의 D1~D4 토픽 집합에 한정한 네 항 분해(신생 점유 변화 `Σ_{k∈D} ΔS_k`의 구성).
# - **D 집합 주의:** D1~D3은 2005–09 대 2020–25 같은 구간의 증가 토픽으로 정의되므로, 그 구간 쌍에서 신생 점유 변화가 양수인 것은 정의상 거의 필연입니다. 부호가 아니라 구성 비율만 해석하세요. D4(2015–19 대 2020–24)가 가장 덜 순환적입니다.
# - 민감도로 FHK와 Price 분해를 같은 입력으로 돌려 항 비율이 어떻게 달라지는지 표로 만듭니다.

# ## S6-3. 귀무 대비 초과 진입분 (6.2)
# "진입 저자가 지속 저자와 같은 토픽 선택을 했다면"의 기대치를 만듭니다.
# 1. 저널×연도 셀 (j, y)마다 지속 저자의 토픽 분포 `P_jyk`를 구합니다.
# 2. 진입 저자 논문의 질량을 같은 셀의 지속 저자 분포로 대체한 **기대 진입 항**을 만듭니다: `Σ_(j,y) m_ent(j,y)·(P_jyk − S̄_k)`.
# 3. **초과분 = 관측 진입 항 − 기대 진입 항**, 토픽별로 구하고, 쌍마다 `½Σ_k|초과분_k|`로 요약합니다. 비율이 아니라 **절대 초과분**으로 보고합니다.
# 4. 같은 방식으로 퇴출 쪽(퇴출 저자를 같은 셀 지속 저자 분포로 대체)도 계산합니다. 대칭으로 해석하지 마세요.
# - **한계(문장으로 씁니다):** 지속 저자는 선택된 다작 저자라 "기준 분포"가 중립이 아닙니다. 지속 저자 질량 가중 결과를 병행하고 한계로 명시합니다.
# - **재현 점검:** 기존에 본 값(전환 excess 0.035~0.068, 저널 내 비중 74~88%)을 새 코드가 가중치와 정의가 같은 설정에서 비슷하게 내는지 봅니다. 이것은 코드 검증용이며 새 코드를 기존 값에 맞춰 조정하지 않습니다. 정의가 달라 값이 다르면 차이의 이유를 CHANGELOG에 적습니다.

# ## S6-4. 층화 순열: 음성 대조 (6.3)
# - 저널×연도 셀 안에서 "지속/진입" 라벨만 섞고 분해와 초과분을 다시 계산합니다(B=1000, 제안).
# - **기대:** 라벨이 무의미하면 초과 진입분은 0 근처, 저널 내 경로 성분도 0 근처여야 합니다. 이 점검은 코드 오류와 "저널 구성만으로 생기는 가짜 초과"를 가려냅니다.
# - **보고 방식:** 순열 z값은 보고하지 않습니다(공저로 독립이 아니라 z의 해석이 무너집니다). 순열 분포의 범위와 관측값의 위치(백분위)만 그림으로 보여 줍니다.
# - **셀 단위 주의:** 저자는 여러 셀에 걸쳐 있으므로, 라벨을 저자 단위로 섞으면 셀 간 정합이 깨집니다. 라벨 단위(저자×기간)와 셀 배정 규칙을 동결에 적어 두세요. 제안은 저자×기간의 "주 저널"이 아니라 **저자-논문 행 단위**로 라벨을 섞는 것입니다. 이 선택은 논문 쪽 군집 구조를 일부 깨므로 한계에 씁니다.

# ## S6-5. 추론 (6.4)
# - **저자·논문 이중 군집 부트스트랩, B=2000.** 저자-논문은 다대다 관계라 저자 군집과 논문 군집을 따로 복원추출하면 구조가 깨집니다. 제안은 **곱셈 가중 부트스트랩**입니다. 저자마다, 논문마다 독립적인 Exp(1) 가중치를 뽑고 저자-논문 행의 가중치를 두 값의 곱으로 둔 뒤 분해 전체를 다시 계산합니다. 이 방식이 이중 군집 구조에 맞는지 동결 전에 확인하세요.
# - **공저 연결 성분 부트스트랩은 쓰지 않습니다.** 거대 성분이 약 74%라 퇴화합니다(계획서 규칙).
# - **보고:** 항별 절대 기여와 초과분의 95% 구간, 그리고 BH-FDR(q=0.05)를 쓰는 경우 검정 묶음(예: 기간 쌍 4개 × 항 4개 = 16개)을 동결에 적습니다. 토픽 단위 검정은 149개라 별도 묶음입니다. 어느 묶음에 FDR을 쓰는지 정해 두세요.
# - 구간은 논문·저자 상관을 반영해 순진한 구간보다 넓어집니다. 그래도 저자 식별 오류(동명이인)는 반영하지 못하므로 S6-7이 필요합니다.

# ## S6-6. 저널의 이중 해석 (6.5)
# 세 가지 해석을 **병기**하고 단정하지 않습니다.
# - **(a) 저널 통제 없음:** S6-2의 분해 그대로.
# - **(b) 저널 고정효과:** 저자 토픽 분포에서 저널 효과를 제거한 뒤(저널×기간 평균을 뺀 잔차 또는 저널 내 토픽 비중) 같은 분해를 반복합니다.
# - **(c) 신규-지속 차이의 경로 분해:** 진입 저자 토픽 분포 `E_k`와 지속 저자 분포 `P_k`의 차이를 저널 구성 경로와 저널 내 경로로 나눕니다.
#   - 저널 내: `Σ_j ((e_j+p_j)/2)·(E_jk − P_jk)`
#   - 저널 간: `Σ_j ((E_jk+P_jk)/2)·(e_j − p_j)`
#   - (`e_j`, `p_j`는 진입, 지속 저자의 저널 j 질량 비중) 두 항의 합이 `E_k − P_k`와 같아야 합니다(불변식).
# - **기존 결과가 가리키는 쟁점:** 기존에 본 값은 진입 초과분의 74~88%가 저널 내에서 나오는데, 신규-지속 gap의 저널 내 비중은 10~17%라는 것이었습니다. 이는 "진입과 지속 저자가 쓰는 저널이 다르다"는 것과 "같은 저널 안의 선택 차이로 초과가 생긴다"가 다른 수준의 질문임을 뜻합니다. 두 결과가 어떻게 양립하는지(초과분은 셀 내 대체 기준이고, gap은 전체 분포 차이)를 본문에서 정의와 함께 구분해 설명해야 합니다. 이 숫자는 이미 본 결과이므로 확증이 아니라 "사전 명시 확인"으로 씁니다.

# 교통 분야 학술 논문 약 11만 편을 모았습니다. 이 논문들은 주제별로 150묶음으로 나뉘어 있습니다. 연구는 이 묶음들이 시간에 따라 어떻게 커지고 작아졌는지 추적합니다.
# 도서관 비유가 가장 쉽습니다. 25년치 교통 논문이 쌓여 있고, 어느 해부터 "자율주행", "딥러닝" 서가가 갑자기 커졌다고 합시다. 이때 두 가지 착시를 의심해야 합니다.
# - **구성 착시:** 연구가 진짜 변한 게 아니라, 특정 학술지(예: IEEE T-ITS)가 논문을 더 많이 실어서 커 보일 수 있습니다.
# - **측정 착시:** 논문을 주제로 분류하는 도구(임베딩)가 어떤 해에 더 많은 논문을 잡았을 수 있습니다.
# 그래서 핵심 질문은 이렇습니다. "교통 연구의 주제 지형은 어느 시점에 갑자기 바뀐 **체제 전환**인가, 아니면 **연속적인 변화**인가? 그리고 그 변화는 누가(기존 연구자의 전향인가, 신규 진입인가), 어디서(어느 나라) 만든 것인가?"

def build_rows():

    pall = pal.merge(F[["pid", "year"]], on="pid")                       # 전 연도(주제 없는 논문 포함): 진입·복귀·퇴출 판별용
    first_all = pall.groupby("name").year.min(); last_all = pall.groupby("name").year.max()
    mx = pall.groupby(["name", "year"]).size().groupby(level=0).max()
    topics = np.array(sorted(pd.read_csv(S3/"L7_topic_grade.csv").topic.astype(int))); tix = {t: i for i, t in enumerate(topics)}
    A = A.assign(ti=A.topic150.astype(int).map(tix))

    risk = pd.read_csv(DATA/"F2_risk_names.csv"); amb = set(risk[tf(risk.ambiguous)].name_norm); hv = set(risk[tf(risk.heavy)].name_norm)
    X = {"base": amb | hv, "ambig_only": amb, "heavy_only": hv, "both_only": amb & hv,
         "heavy_8": amb | set(mx[mx >= 8].index), "heavy_20": amb | set(mx[mx >= 20].index), "none": set()}

def variant_rows(rows, Xset):
    R = rows[~rows.name.isin(Xset)].copy(); R["w"] = 1.0 / R.groupby("pid").pid.transform("size"); return R

def pair_stats(R, a, b, K, D, first_all, last_all):
    r0, r1 = R[R.year.between(*P[a])], R[R.year.between(*P[b])]; N0, N1 = r0.w.sum(), r1.w.sum()
    names = pd.Index(pd.concat([r0.name, r1.name]).unique()); ai = pd.Series(np.arange(len(names)), index=names)
    mat = lambda r, N: sp.coo_matrix((r.w.values/N, (ai.reindex(r.name).values, r.ti.values)), shape=(len(names), K)).tocsr()
    M0, M1 = mat(r0, N0), mat(r1, N1); w0, w1 = np.asarray(M0.sum(1)).ravel(), np.asarray(M1.sum(1)).ravel()
    S0, S1 = np.asarray(M0.sum(0)).ravel(), np.asarray(M1.sum(0)).ravel()
    if abs(S0.sum()-1) > TOL or abs(S1.sum()-1) > TOL: raise Halt("불변식 실패: 질량 보존")
    cont, ent, ex = (w0 > 0) & (w1 > 0), (w0 == 0) & (w1 > 0), (w0 > 0) & (w1 == 0)
    fy = pd.Series(names.map(first_all)).fillna(9999).values; ly = pd.Series(names.map(last_all)).fillna(-1).values
    ret = ent & (fy < P[a][0]); new = ent & ~ret; fin = ex & (ly <= P[a][1]); gap = ex & ~fin
    C0, C1 = M0[cont].toarray(), M1[cont].toarray(); wc0, wc1 = w0[cont], w1[cont]; s0, s1 = C0/wc0[:, None], C1/wc1[:, None]
    dS = S1 - S0; Sb = (S0 + S1)/2; dw = wc1 - wc0
    tm = dict(adapt=(((wc0+wc1)/2)[:, None]*(s1-s0)).sum(0), realloc=((((s0+s1)/2) - Sb)*dw[:, None]).sum(0),
              entry_new=np.asarray(M1[new].sum(0)).ravel() - Sb*w1[new].sum(), entry_ret=np.asarray(M1[ret].sum(0)).ravel() - Sb*w1[ret].sum(),
              exit_final=-(np.asarray(M0[fin].sum(0)).ravel() - Sb*w0[fin].sum()), exit_gap=-(np.asarray(M0[gap].sum(0)).ravel() - Sb*w0[gap].sum()))
    if np.abs(sum(tm.values()) - dS).max() > TOL: raise Halt("불변식 실패: 중점 분해 합 != 총변화")
    # FHK
    fh = dict(within=(wc0[:, None]*(s1-s0)).sum(0), between=((s0 - S0)*dw[:, None]).sum(0), cross=((s1-s0)*dw[:, None]).sum(0),
              entry=np.asarray(M1[ent].sum(0)).ravel() - S0*w1[ent].sum(), exit=-(np.asarray(M0[ex].sum(0)).ravel() - S0*w0[ex].sum()))
    if np.abs(sum(fh.values()) - dS).max() > TOL: raise Halt("불변식 실패: FHK 분해 합 != 총변화")
    ab = lambda v: 0.5*np.abs(v).sum(); out = dict(pair=f"{a}->{b}", total_half=ab(dS), n_papers0=int(r0.pid.nunique()), n_papers1=int(r1.pid.nunique()))
    tot = sum(ab(v) for v in tm.values())
    for k, v in tm.items(): out["abs_"+k] = ab(v); out["share_"+k] = ab(v)/tot
    totf = sum(ab(v) for v in fh.values())
    for k, v in fh.items(): out["fhk_share_"+k] = ab(v)/totf
    # 초과 진입분: 같은 저널x연도 셀의 지속 저자 분포로 대체
    cls = pd.Series(np.where(cont, "c", np.where(ent, "e", "x")), index=names); r1 = r1.assign(c=cls.reindex(r1.name).values)
    cellmass = lambda c: (r1[r1.c == c].groupby(["venue", "year", "ti"]).w.sum()/N1).unstack(fill_value=0).reindex(columns=range(K), fill_value=0)
    Pc, Em = cellmass("c"), cellmass("e"); common = Em.index.intersection(Pc.index[Pc.sum(1) > 0])
    out["dropped_entrant_share"] = 1 - Em.loc[common].values.sum()/max(Em.values.sum(), 1e-12)
    Pn = Pc.loc[common].div(Pc.loc[common].sum(1), axis=0); exp = Pn.mul(Em.loc[common].sum(1), axis=0).sum(0).values
    exc = Em.loc[common].sum(0).values - exp; out["excess_half"] = ab(exc)
    for k, m in D.items(): out[f"excess_D_{k}"] = float(exc[m].sum())
    # 저널 경로 분해(신규(진입) - 지속, t1)
    vm = lambda c: (r1[r1.c == c].groupby(["venue", "ti"]).w.sum()).unstack(fill_value=0).reindex(columns=range(K), fill_value=0)
    Ev, Pv = vm("e"), vm("c"); V = Ev.index.union(Pv.index); Ev, Pv = Ev.reindex(V, fill_value=0).values, Pv.reindex(V, fill_value=0).values
    e, p = Ev.sum(1)/Ev.sum(), Pv.sum(1)/Pv.sum(); dist = lambda M: np.divide(M, M.sum(1, keepdims=True), out=np.zeros_like(M), where=M.sum(1, keepdims=True) > 0)
    Ej, Pj = dist(Ev), dist(Pv); wi = (((e+p)/2)[:, None]*(Ej-Pj)).sum(0); bt = ((((Ej+Pj)/2))*(e-p)[:, None]).sum(0)
    if np.abs(wi + bt - (Ev.sum(0)/Ev.sum() - Pv.sum(0)/Pv.sum())).max() > TOL: raise Halt("불변식 실패: 저널 경로 분해")
    out["path_within_abs"], out["path_between_abs"] = np.abs(wi).sum(), np.abs(bt).sum(); out["path_within_share"] = out["path_within_abs"]/(out["path_within_abs"]+out["path_between_abs"])
    out["K2_within_gt_between"] = int(out["path_within_abs"] > out["path_between_abs"]); out["K3_adapt_gt_entry"] = int(out["abs_adapt"] > out["abs_entry_new"] + out["abs_entry_ret"])
    out["K1_sign_D4"] = int(np.sign(out["excess_D_D4"]))
    return out

def homonym():
    rows, topics, X, D, first_all, last_all = build_rows(); K = len(topics); L = []
    print("변형별 제외 이름 수:", {k: len(v) for k, v in X.items()})
    for v, Xs in X.items():
        R = variant_rows(rows, Xs); print(f"[{v}] 저자 행 {len(R):,} | 논문 {R.pid.nunique():,}")
        for a, b in PAIRS: L.append(dict(variant=v, **pair_stats(R, a, b, K, D, first_all, last_all)))
    T = pd.DataFrame(L); T.to_csv(S6/"homonym_variants_grid.csv", index=False, encoding="utf-8-sig")
    keys = ["total_half", "share_adapt", "share_realloc", "share_entry_new", "share_entry_ret", "share_exit_final", "excess_half", "path_within_share"]
    rng = T.groupby("pair")[keys].agg(["min", "max"]).round(4); rng.to_csv(S6/"homonym_range.csv", encoding="utf-8-sig")
    print("\n[변형 7종 범위(최소~최대)]\n", rng.to_string())
    base = T[T.variant == "base"].set_index("pair"); fl = []
    for kk in ["K1_sign_D4", "K2_within_gt_between", "K3_adapt_gt_entry"]:
        for pair, g in T.groupby("pair"): fl.append(dict(var=kk, pair=pair, base=int(base.loc[pair, kk]), frac_diff=float((g[kk] != base.loc[pair, kk]).mean())))
    FL = pd.DataFrame(fl); FL["pass_le_0.25"] = FL.frac_diff <= 0.25; FL.to_csv(S6/"homonym_direction_split.csv", index=False)
    print("\n[주 변형(base)과 방향이 다른 변형 비율]\n", FL.to_string(index=False))
    print("※ K1의 마지막 쌍(P1519->P2025)은 D4가 2015-19 대 2020-24로 정의되어 순환입니다. 판정에서 제외하고 보고만 하세요.")
    print("\n[FHK 민감도: base, 항별 절대기여 몫]\n", base[[c for c in base.columns if c.startswith("fhk_share_")]].round(3).to_string())
    print("\n[재현 점검: base(equal 가중) vs 이전 s6_run 출력. 차이는 기록만, 코드 조정 금지]")
    for pair, r in REF.items():
        print(pair, {k: (round(float(base.loc[pair, k]), 3), v, round(float(base.loc[pair, k]) - v, 3)) for k, v in r.items()})
    print("(형식: (이번, 이전, 차이)). 이전 값은 소수 셋째 자리까지만 있고 IPW·가중 정의가 다를 수 있습니다. 0.01 이상 차이가 나면 CHANGELOG에 정의 차이를 적으세요.")
    return T

def pair_stats(R, a, b, K, D, first_all, last_all):
    r0, r1 = R[R.year.between(*P[a])], R[R.year.between(*P[b])]; N0, N1 = r0.w.sum(), r1.w.sum()
    names = pd.Index(pd.concat([r0.name, r1.name]).unique()); ai = pd.Series(np.arange(len(names)), index=names)
    mat = lambda r, N: sp.coo_matrix((r.w.values/N, (ai.reindex(r.name).values, r.ti.values)), shape=(len(names), K)).tocsr()
    M0, M1 = mat(r0, N0), mat(r1, N1); w0, w1 = np.asarray(M0.sum(1)).ravel(), np.asarray(M1.sum(1)).ravel()
    S0, S1 = np.asarray(M0.sum(0)).ravel(), np.asarray(M1.sum(0)).ravel()
    if abs(S0.sum()-1) > TOL or abs(S1.sum()-1) > TOL: raise Halt("불변식 실패: 질량 보존")
    cont, ent, ex = (w0 > 0) & (w1 > 0), (w0 == 0) & (w1 > 0), (w0 > 0) & (w1 == 0)
    fy = pd.Series(names.map(first_all)).fillna(9999).values; ly = pd.Series(names.map(last_all)).fillna(-1).values
    ret = ent & (fy < P[a][0]); new = ent & ~ret; fin = ex & (ly <= P[a][1]); gap = ex & ~fin
    C0, C1 = M0[cont].toarray(), M1[cont].toarray(); wc0, wc1 = w0[cont], w1[cont]; s0, s1 = C0/wc0[:, None], C1/wc1[:, None]
    dS = S1 - S0; Sb = (S0 + S1)/2; dw = wc1 - wc0
    tm = dict(adapt=(((wc0+wc1)/2)[:, None]*(s1-s0)).sum(0), realloc=((((s0+s1)/2) - Sb)*dw[:, None]).sum(0),
              entry_new=np.asarray(M1[new].sum(0)).ravel() - Sb*w1[new].sum(), entry_ret=np.asarray(M1[ret].sum(0)).ravel() - Sb*w1[ret].sum(),
              exit_final=-(np.asarray(M0[fin].sum(0)).ravel() - Sb*w0[fin].sum()), exit_gap=-(np.asarray(M0[gap].sum(0)).ravel() - Sb*w0[gap].sum()))
    if np.abs(sum(tm.values()) - dS).max() > TOL: raise Halt("불변식 실패: 중점 분해 합 != 총변화")
    # FHK
    fh = dict(within=(wc0[:, None]*(s1-s0)).sum(0), between=((s0 - S0)*dw[:, None]).sum(0), cross=((s1-s0)*dw[:, None]).sum(0),
              entry=np.asarray(M1[ent].sum(0)).ravel() - S0*w1[ent].sum(), exit=-(np.asarray(M0[ex].sum(0)).ravel() - S0*w0[ex].sum()))
    if np.abs(sum(fh.values()) - dS).max() > TOL: raise Halt("불변식 실패: FHK 분해 합 != 총변화")
    ab = lambda v: 0.5*np.abs(v).sum(); out = dict(pair=f"{a}->{b}", total_half=ab(dS), n_papers0=int(r0.pid.nunique()), n_papers1=int(r1.pid.nunique()))
    tot = sum(ab(v) for v in tm.values())
    for k, v in tm.items(): out["abs_"+k] = ab(v); out["share_"+k] = ab(v)/tot
    totf = sum(ab(v) for v in fh.values())
    for k, v in fh.items(): out["fhk_share_"+k] = ab(v)/totf
    # 초과 진입분: 같은 저널x연도 셀의 지속 저자 분포로 대체
    cls = pd.Series(np.where(cont, "c", np.where(ent, "e", "x")), index=names); r1 = r1.assign(c=cls.reindex(r1.name).values)
    cellmass = lambda c: (r1[r1.c == c].groupby(["venue", "year", "ti"]).w.sum()/N1).unstack(fill_value=0).reindex(columns=range(K), fill_value=0)
    Pc, Em = cellmass("c"), cellmass("e"); common = Em.index.intersection(Pc.index[Pc.sum(1) > 0])
    out["dropped_entrant_share"] = 1 - Em.loc[common].values.sum()/max(Em.values.sum(), 1e-12)
    Pn = Pc.loc[common].div(Pc.loc[common].sum(1), axis=0); exp = Pn.mul(Em.loc[common].sum(1), axis=0).sum(0).values
    exc = Em.loc[common].sum(0).values - exp; out["excess_half"] = ab(exc)
    for k, m in D.items(): out[f"excess_D_{k}"] = float(exc[m].sum())
    # 저널 경로 분해(신규(진입) - 지속, t1)
    vm = lambda c: (r1[r1.c == c].groupby(["venue", "ti"]).w.sum()).unstack(fill_value=0).reindex(columns=range(K), fill_value=0)
    Ev, Pv = vm("e"), vm("c"); V = Ev.index.union(Pv.index); Ev, Pv = Ev.reindex(V, fill_value=0).values, Pv.reindex(V, fill_value=0).values
    e, p = Ev.sum(1)/Ev.sum(), Pv.sum(1)/Pv.sum(); dist = lambda M: np.divide(M, M.sum(1, keepdims=True), out=np.zeros_like(M), where=M.sum(1, keepdims=True) > 0)
    Ej, Pj = dist(Ev), dist(Pv); wi = (((e+p)/2)[:, None]*(Ej-Pj)).sum(0); bt = ((((Ej+Pj)/2))*(e-p)[:, None]).sum(0)
    if np.abs(wi + bt - (Ev.sum(0)/Ev.sum() - Pv.sum(0)/Pv.sum())).max() > TOL: raise Halt("불변식 실패: 저널 경로 분해")
    out["path_within_abs"], out["path_between_abs"] = np.abs(wi).sum(), np.abs(bt).sum(); out["path_within_share"] = out["path_within_abs"]/(out["path_within_abs"]+out["path_between_abs"])
    out["K2_within_gt_between"] = int(out["path_within_abs"] > out["path_between_abs"]); out["K3_adapt_gt_entry"] = int(out["abs_adapt"] > out["abs_entry_new"] + out["abs_entry_ret"])
    out["K1_sign_D4"] = int(np.sign(out["excess_D_D4"]))
    return out

def pair_stats(R, a, b, K, D, first_all, last_all):
    r0, r1 = R[R.year.between(*P[a])], R[R.year.between(*P[b])]; N0, N1 = r0.w.sum(), r1.w.sum()
    names = pd.Index(pd.concat([r0.name, r1.name]).unique()); ai = pd.Series(np.arange(len(names)), index=names)
    mat = lambda r, N: sp.coo_matrix((r.w.values/N, (ai.reindex(r.name).values, r.ti.values)), shape=(len(names), K)).tocsr()
    M0, M1 = mat(r0, N0), mat(r1, N1); w0, w1 = np.asarray(M0.sum(1)).ravel(), np.asarray(M1.sum(1)).ravel()
    S0, S1 = np.asarray(M0.sum(0)).ravel(), np.asarray(M1.sum(0)).ravel()
    if abs(S0.sum()-1) > TOL or abs(S1.sum()-1) > TOL: raise Halt("불변식 실패: 질량 보존")
    cont, ent, ex = (w0 > 0) & (w1 > 0), (w0 == 0) & (w1 > 0), (w0 > 0) & (w1 == 0)
    fy = pd.Series(names.map(first_all)).fillna(9999).values; ly = pd.Series(names.map(last_all)).fillna(-1).values
    ret = ent & (fy < P[a][0]); new = ent & ~ret; fin = ex & (ly <= P[a][1]); gap = ex & ~fin
    C0, C1 = M0[cont].toarray(), M1[cont].toarray(); wc0, wc1 = w0[cont], w1[cont]; s0, s1 = C0/wc0[:, None], C1/wc1[:, None]
    dS = S1 - S0; Sb = (S0 + S1)/2; dw = wc1 - wc0
    tm = dict(adapt=(((wc0+wc1)/2)[:, None]*(s1-s0)).sum(0), realloc=((((s0+s1)/2) - Sb)*dw[:, None]).sum(0),
              entry_new=np.asarray(M1[new].sum(0)).ravel() - Sb*w1[new].sum(), entry_ret=np.asarray(M1[ret].sum(0)).ravel() - Sb*w1[ret].sum(),
              exit_final=-(np.asarray(M0[fin].sum(0)).ravel() - Sb*w0[fin].sum()), exit_gap=-(np.asarray(M0[gap].sum(0)).ravel() - Sb*w0[gap].sum()))
    if np.abs(sum(tm.values()) - dS).max() > TOL: raise Halt("불변식 실패: 중점 분해 합 != 총변화")
    # FHK
    fh = dict(within=(wc0[:, None]*(s1-s0)).sum(0), between=((s0 - S0)*dw[:, None]).sum(0), cross=((s1-s0)*dw[:, None]).sum(0),
              entry=np.asarray(M1[ent].sum(0)).ravel() - S0*w1[ent].sum(), exit=-(np.asarray(M0[ex].sum(0)).ravel() - S0*w0[ex].sum()))
    if np.abs(sum(fh.values()) - dS).max() > TOL: raise Halt("불변식 실패: FHK 분해 합 != 총변화")
    ab = lambda v: 0.5*np.abs(v).sum(); out = dict(pair=f"{a}->{b}", total_half=ab(dS), n_papers0=int(r0.pid.nunique()), n_papers1=int(r1.pid.nunique()))
    tot = sum(ab(v) for v in tm.values())
    for k, v in tm.items(): out["abs_"+k] = ab(v); out["share_"+k] = ab(v)/tot
    totf = sum(ab(v) for v in fh.values())
    for k, v in fh.items(): out["fhk_share_"+k] = ab(v)/totf
    # 초과 진입분: 같은 저널x연도 셀의 지속 저자 분포로 대체
    cls = pd.Series(np.where(cont, "c", np.where(ent, "e", "x")), index=names); r1 = r1.assign(c=cls.reindex(r1.name).values)
    cellmass = lambda c: (r1[r1.c == c].groupby(["venue", "year", "ti"]).w.sum()/N1).unstack(fill_value=0).reindex(columns=range(K), fill_value=0)
    Pc, Em = cellmass("c"), cellmass("e"); common = Em.index.intersection(Pc.index[Pc.sum(1) > 0])
    out["dropped_entrant_share"] = 1 - Em.loc[common].values.sum()/max(Em.values.sum(), 1e-12)
    Pn = Pc.loc[common].div(Pc.loc[common].sum(1), axis=0); exp = Pn.mul(Em.loc[common].sum(1), axis=0).sum(0).values
    exc = Em.loc[common].sum(0).values - exp; out["excess_half"] = ab(exc)
    for k, m in D.items(): out[f"excess_D_{k}"] = float(exc[m].sum())
    # 저널 경로 분해(신규(진입) - 지속, t1)
    vm = lambda c: (r1[r1.c == c].groupby(["venue", "ti"]).w.sum()).unstack(fill_value=0).reindex(columns=range(K), fill_value=0)
    Ev, Pv = vm("e"), vm("c"); V = Ev.index.union(Pv.index); Ev, Pv = Ev.reindex(V, fill_value=0).values, Pv.reindex(V, fill_value=0).values
    e, p = Ev.sum(1)/Ev.sum(), Pv.sum(1)/Pv.sum(); dist = lambda M: np.divide(M, M.sum(1, keepdims=True), out=np.zeros_like(M), where=M.sum(1, keepdims=True) > 0)
    Ej, Pj = dist(Ev), dist(Pv); wi = (((e+p)/2)[:, None]*(Ej-Pj)).sum(0); bt = ((((Ej+Pj)/2))*(e-p)[:, None]).sum(0)
    if np.abs(wi + bt - (Ev.sum(0)/Ev.sum() - Pv.sum(0)/Pv.sum())).max() > TOL: raise Halt("불변식 실패: 저널 경로 분해")
    out["path_within_abs"], out["path_between_abs"] = np.abs(wi).sum(), np.abs(bt).sum(); out["path_within_share"] = out["path_within_abs"]/(out["path_within_abs"]+out["path_between_abs"])
    out["K2_within_gt_between"] = int(out["path_within_abs"] > out["path_between_abs"]); out["K3_adapt_gt_entry"] = int(out["abs_adapt"] > out["abs_entry_new"] + out["abs_entry_ret"])
    out["K1_sign_D4"] = int(np.sign(out["excess_D_D4"]))
    return out

def homonym():
    rows, topics, X, D, first_all, last_all = build_rows(); K = len(topics); L = []
    print("변형별 제외 이름 수:", {k: len(v) for k, v in X.items()})
    for v, Xs in X.items():
        R = variant_rows(rows, Xs); print(f"[{v}] 저자 행 {len(R):,} | 논문 {R.pid.nunique():,}")
        for a, b in PAIRS: L.append(dict(variant=v, **pair_stats(R, a, b, K, D, first_all, last_all)))
    T = pd.DataFrame(L); T.to_csv(S6/"homonym_variants_grid.csv", index=False, encoding="utf-8-sig")
    keys = ["total_half", "share_adapt", "share_realloc", "share_entry_new", "share_entry_ret", "share_exit_final", "excess_half", "path_within_share"]
    rng = T.groupby("pair")[keys].agg(["min", "max"]).round(4); rng.to_csv(S6/"homonym_range.csv", encoding="utf-8-sig")
    print("\n[변형 7종 범위(최소~최대)]\n", rng.to_string())
    base = T[T.variant == "base"].set_index("pair"); fl = []
    for kk in ["K1_sign_D4", "K2_within_gt_between", "K3_adapt_gt_entry"]:
        for pair, g in T.groupby("pair"): fl.append(dict(var=kk, pair=pair, base=int(base.loc[pair, kk]), frac_diff=float((g[kk] != base.loc[pair, kk]).mean())))
    FL = pd.DataFrame(fl); FL["pass_le_0.25"] = FL.frac_diff <= 0.25; FL.to_csv(S6/"homonym_direction_split.csv", index=False)
    print("\n[주 변형(base)과 방향이 다른 변형 비율]\n", FL.to_string(index=False))
    print("※ K1의 마지막 쌍(P1519->P2025)은 D4가 2015-19 대 2020-24로 정의되어 순환입니다. 판정에서 제외하고 보고만 하세요.")
    print("\n[FHK 민감도: base, 항별 절대기여 몫]\n", base[[c for c in base.columns if c.startswith("fhk_share_")]].round(3).to_string())
    print("\n[재현 점검: base(equal 가중) vs 이전 s6_run 출력. 차이는 기록만, 코드 조정 금지]")
    for pair, r in REF.items():
        print(pair, {k: (round(float(base.loc[pair, k]), 3), v, round(float(base.loc[pair, k]) - v, 3)) for k, v in r.items()})
    print("(형식: (이번, 이전, 차이)). 이전 값은 소수 셋째 자리까지만 있고 IPW·가중 정의가 다를 수 있습니다. 0.01 이상 차이가 나면 CHANGELOG에 정의 차이를 적으세요.")
    return T
