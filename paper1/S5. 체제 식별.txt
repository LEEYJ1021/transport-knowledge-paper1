# ## S5-2. 변화점 탐지

# ### 2.1 주 방법: 제약 군집화 (동적계획)

# - 인접 연도만 묶는 구간 분할을 구하되 최소 구간 길이 3년, 최대 구간 수 6(동결 규칙)으로 합니다.
# - 구간 비용은 구간 내 연도 벡터의 가중 제곱 편차입니다. 가중치는 `4·n_t`입니다(**제안**).
#   - 근거: `4·n_t·‖√p̂_t − √p_t‖²`은 대략 자유도 K−1의 카이제곱입니다. 이렇게 하면 소표본 연도의 잡음이 자동으로 커진 만큼 비용에서 낮게 반영됩니다.
#   - 가중 평균으로 구간 중심을 계산합니다.
# - 구간 수 k=1~6 각각의 최적 분할과 총비용 곡선을 모두 저장합니다. 하나만 고르지 않고 곡선을 보고합니다.

# ### 2.2 벌점 (제안, 동결 전에 확정)

# - BIC형 벌점은 "구간당 (K−1)개 모수"를 가정합니다. 그러나 관측은 논문 독립이 아니므로(같은 저널, 공저) 비용이 과분산입니다.
# - 과분산 계수 φ를 귀무에서 추정합니다. 연도 라벨을 저널 안에서 섞은 자료(S5-4의 N1)에서 "구간 하나(k=1)의 연도당 평균 비용 ÷ (K−1)"의 중앙값을 φ로 씁니다.
# - 벌점은 `φ·(K−1)·c·log T`입니다(c=1.0, 초기값). c는 임의 출발값이므로 c∈{0.5, 1, 2} 격자 결과를 같이 저장하고 어느 c에서든 같은 변화점인지를 보고합니다(multiverse 성격).
# - 이 φ 추정은 귀무 자료를 쓰므로, S5-4의 귀무 생성 코드를 먼저 돌려 φ만 확정하고 변화점 위치는 보지 않는 순서로 하세요.

# ### 2.3 교차 확인 (단변량)

# - 주제 유효수, HHI, D3 점유율 각각에 Bai-Perron형 분할(최소 구간 3년, k 최대 6)을 적용하고, 다변량 변화점과 ±1년 안에서 일치하는지 표로 만듭니다.
# - 단변량은 "무슨 성격의 변화인가"를 설명하는 용도입니다. 다변량 결과를 대체하지 않습니다.

# ### 2.4 세 표본 비교

# - `all`, `fixed14`, `within` 각각에서 k별 최적 분할과 선택된 k를 나란히 놓습니다.
# - 해석 규칙은 5.7의 유형 정의를 따릅니다. 여기서는 숫자만 만듭니다.

# ## S5-4. 가짜 체제 방어 (두 귀무와 보조 검정)

# ### 4.1 귀무 N1: 저널 내 시간 구조 제거 (제안, 계획서의 "라벨 순열" 대체)

# - 저널별로 연도 라벨을 섞습니다. 저널×연도 논문 수는 유지하고, 어느 논문이 어느 해에 속하는지만 무작위로 바꿉니다.
# - 효과: 저널 규모의 연도별 변화(구성 효과)는 남고, 저널 안의 토픽 변화는 사라집니다. 그래서 "구성만으로 어떤 변화점이 잡히는가"를 직접 보여 줍니다.
# - 이 귀무에서 변화점이 잡히면 구성 체제 후보이고, 안 잡히면 저널 내 변화가 있다는 뜻입니다(유형 분류에 직접 사용).
# - 완전 무변화 귀무(N0)도 병행합니다. 모든 논문의 연도 라벨을 전체에서 섞습니다(표본 크기만 유지). φ 추정과 "아무 구조도 없을 때 몇 개 잡히는가"의 바닥으로 씁니다.
# - B=500. 각 반복에서 S5-2를 그대로 돌려 선택 k, 최대 JS 점프, 총비용 감소율을 저장합니다.

# ### 4.2 귀무 N2: 완만 추세

# - 토픽별 연도 비중에 선형 추세를 적합하고(음수는 0으로 자르고 합이 1이 되도록 재정규화), 연도별 `n_t`로 다항 표집해서 재탐지합니다.
# - **핵심 통계는 "k개 구간의 비용 감소율"입니다.** 구간 수 자체는 추세 자료에서도 늘어날 수 있으므로, 관측의 k 구간 분할이 1구간 대비 줄이는 비용의 비율을 귀무 분포와 비교합니다.
# - 비교 대안으로 구간별 선형(piecewise linear) 적합 대비 구간별 상수(piecewise constant) 적합의 우열도 보고합니다(체제=점프, 추세=연속이라는 구분을 직접 검정).
# - 통과 기준: 관측치가 두 귀무 상위 5% 밖(p<0.05)이어야 합니다. N0, N1, N2 모두 보고합니다.

# ### 4.3 주제 반분 재현 (B=200)

# - 유효 149개 토픽을 무작위 반분하여 한쪽에서 변화점을 찾고, 다른 쪽에서 ±1년 안에 재현되는 비율을 구합니다. 통과 기준은 0.50 이상입니다(동결 규칙).
# - 교차 적합 병행: 한쪽으로 구간을 정하고 다른 쪽으로 구간 간 비교를 하여 이중 사용을 막습니다(계획서 5.8).

# ### 4.4 추세 제거 후 재탐지

# - 각 토픽 비중에서 선형 추세를 제거하고 재탐지합니다. 변화점이 유지되면 "추세와 구분되는 점프"로 해석합니다.
